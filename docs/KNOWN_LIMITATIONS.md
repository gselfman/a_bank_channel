# Что проверено и что требуется проверить на сервере

- Локальные unit tests покрывают порядок, повторный импорт, обработку известных и неоднозначных сбоев, остановку, лимиты расходов, HTML-ссылки, лимит подписи, доказательства и парсер Telegram на фикстуре.
- Нет настоящих токенов/ключей, не было отправки в Telegram и платных запросов OpenAI. Нет SSH-доступа к серверу, развёртывание ещё не выполнено. Web search в рабочей среде не смог открыть t.me/s/altynwallet; это НЕ доказывает недоступность страницы с вашего сервера. Live-тест парсера обязателен при установке.
- Публичная HTML-лента Telegram не является официальным API и может поменяться/ограничить доступ. Парсер тогда выдаёт ошибку; курсор не продвигается. Редактирование/удаление старых сообщений Telegram не отслеживается, собираются новые номера. Глубина догоняющей пагинации ограничена, при превышении сбор останавливается.
- Сайт обходится в пределах allowlist и site_max_pages, без исполнения JavaScript. Часть динамических данных может отсутствовать; нет полной гарантии охвата всех услуг/страниц. Короткая/закрытая/challenge-страница приводит к ошибке, пустые выводы не заменяют доказательства. На момент генерации используются максимум 12 свежих страниц по 12000 символов; если нужное доказательство не попало, материал hold.
- Источники обновляются раз в poll_seconds. Никакого live-контроля фактической платёжной доступности нет. Проверка цитат детерминированная, проверка смысла — человеком. Поиск смысловых повторов — подсказка модели плюс exact-dedup, не гарантированная семантическая дедупликация.
- Локальный месячный бюджет — сумма консервативных reservations, не реальный биллинг. Конкретные модели/цены проверяются при установке; значения по умолчанию не означают «последняя/лучшая модель». API отдельно от ChatGPT. Изображения генерируются при явном image или ai_images_enabled; после генерации требуют визуального review.
- Панели в браузере/авторизации администраторов/Telegram-кнопок согласования нет. Управление через SSH CLI и локальный HTML review. Нет подключения банковских счетов, AML или реальных денежных тестов.
- Новые AI-посты не публикуются без approve. По умолчанию AI и расписание выключены, бюджет 0, отправка paused. Утверждённый пакет можно отправить без OpenAI.
- Навигация обновляется finalize по всем отправленным темам; worker вызывает finalize после новых отправок. Если обновление не удалось, повторите finalize вручную. Навигация ограничена 4096 символами: при росте канала потребуется разбивка на разделы. Автоматическое редактирование старых тарифов и объявление восстановления СБП не реализованы: изменения попадают в очередь человеку.
- Не заявляется гарантия отсутствия дублей при любых авариях: неопределённая отправка требует ручного reconciliation. Один worker, один persistent state. Восстановление старой БД требует сверки с каналом.
